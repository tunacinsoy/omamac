# AltTab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AltTab joins the app catalog (Productivity), and picking it makes Cmd+Tab open AltTab.

**Architecture:** App files get an optional `defaults=` line (`<domain> <key> <type> <value>`), read by `apps_load` into `APP_DEFAULTS`. `apps_install` writes those lines right after it installs, reinstalls or adopts the app, and never otherwise, so `omamac update` never rewrites them. AltTab's file carries the hold-key line.

**Tech Stack:** bash 5, bats, macOS `defaults`, Homebrew cask `alt-tab`, Tart VM.

**Spec:** `docs/superpowers/specs/2026-11-27-alt-tab-design.md`

## Global Constraints

- App id `alt-tab`, cask `alt-tab`, bundle `AltTab.app`, label `AltTab`, last in `apps_productivity` (after Raycast, Obsidian).
- The hold key is written at install, reinstall and adoption only; an app Homebrew already has (`brew` state) gets nothing written, on any run.
- No new question, no `omamac configure` entry. Uninstall needs no new code: AltTab not running means macOS's Cmd+Tab.
- Output shows the result only: no extra line for the setting.
- Nothing users see mentions apt, Windows or WSL.

## Review Focus

- **AltTab drops the value on first launch** (its newer versions store shortcuts as an encoded dictionary and delete a value they can't decode). Task 1 proves which value survives before anything is built; Task 4's VM step re-checks it on every VM run.
- **Already from Homebrew, then picked** (`brew install --cask alt-tab` by hand earlier): nothing is written. Test in Task 2.
- **A `defaults` write fails**: the run stops naming "setting up AltTab", like a failed install. Test in Task 2.
- **A password app with a `defaults=` line** would skip the write (the password step doesn't call it): a catalog test forbids the pair. Test in Task 2.
- **A malformed `defaults=` line** (fewer than four words, unknown type): `apps_load` names the file and line. Test in Task 2.
